## About

I graduated cum laude with a B.S. in Computer Science from UMass Dartmouth. I build full-stack apps end to end: a REST API, a database, and a frontend someone can actually use.

I also operate Red Line trains at the MBTA. The commute app below came from that job: one saved trip, live predictions, and a single answer for whether to leave.

English · Arabic · French

## Projects

**[Red Line](https://github.com/WalidAbousoukkar/Red-Line)** · [Live demo](https://red-line-sandy.vercel.app)

A commute screen for one Red Line trip. It stores a home stop, a work stop, and a walk time, then turns MBTA predictions into “leave now” or “wait,” with only the alerts that touch that trip. Next.js, TypeScript, and SQLite, deployed on Vercel.

**[Personal website](https://github.com/WalidAbousoukkar/personal-website)** · [walidabousoukkar.com](https://walidabousoukkar.com)

Portfolio site built with HTML, CSS, and JavaScript. No framework. Hosted on GitHub Pages.

**Knowledge Management System (NUWC)**

Senior capstone for the Naval Undersea Warfare Center, presented to their stakeholders. A searchable document platform with an Angular frontend, a Flask API, and MongoDB, including search, role-based access, and admin tools.

**UMass Connect**

Campus social app: posts, likes, comments, and reposts. React and Tailwind on the frontend, Flask and MongoDB on the backend, with JWT auth.
